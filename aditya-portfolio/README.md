# Aditya Choudhary — Software Engineer Portfolio

A responsive personal portfolio presenting my work across backend engineering, full-stack product development, artificial intelligence, and software systems.

The website uses a dark, futuristic design inspired by digital systems and engineering interfaces. It is dependency-free and can be opened directly in a browser or deployed to any static hosting service.

## Live Portfolio

The public deployment link will be added after the first release.

## Features

- Responsive layout for desktop, tablet, and mobile
- Premium technical-style hero portrait
- Selected software and AI project showcase

- Verified credential and active Nanodegree showcase
- Technology stack and engineering capabilities

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Aadiiiiiii/aditya-portfolio.git
cd aditya-portfolio
```

Then either open `index.html` directly or use the VS Code Live Server extension.

No installation or build command is needed.

## Deployment

Because this is a static website, it can be deployed free of charge with GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

### GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the main branch and root directory.
6. Save and wait for GitHub to publish the site.

After deployment, update the **Live Portfolio** section and use the full deployed URL for the social-preview metadata in `index.html`.
